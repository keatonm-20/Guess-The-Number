# Number Guessing Game 🎮

A simple Python game where the player tries to guess a random number between 1 and 10.

## How it works
- The program generates a random number
- You keep guessing until you get it correct
- It tells you when you're right

## How to run

Make sure you have Python installed, then run Py file in repo.


## Example
Enter Number: 5
Try Again
Enter Number: 8
Correct!
